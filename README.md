## 📝 使用方式

1. 把新 skill 放到 `skills/` 目录下
2. 告诉我「测试 xxx skill」
3. 我测试后更新状态：✅ 可用 / ⚠️ 有问题 / 🔄 测试中 / ❌ 废弃
4. 通过的直接推送到 GitHub

## 🔍 状态说明

| 状态 | 含义 |
|------|------|
| ✅ | 测试通过 |
| ⚠️ | 有问题待修复 |
| 🔄 | 测试中 |
| ❌ | 已废弃 |
